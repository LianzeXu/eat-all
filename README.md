# 小小引力场｜GitHub Pages 版

纯静态、无构建、无后端的手机网页游戏。ZIP 解压后 `index.html` 在项目根目录，上传所有文件到 GitHub 仓库根目录即可发布。

## 本次调优

- 降低初始黑洞半径，并让局内/永久体积提升更小、更渐进。
- 增加星尘数量与场景容量。
- 提高局内三选一经验门槛，降低每次吞噬带来的经验；碎片不再递归分裂，也不提供升级经验，避免成长滚雪球。
- 永久升级价格更高且随等级递增更快；局内结算倍率为小幅加成并设上限。
- 明确区分 **局内限时模式**（75 秒，临时强化只在本局有效）和 **永久成长模式**（用星尘升级，效果长期保留）。

本版不包含广告、支付、兑换码、排行榜或联网功能。

## 本地预览

在项目目录运行：

```bash
python3 -m http.server 8000
```

浏览器访问 `http://localhost:8000`。本版使用原生 Canvas，不依赖 Phaser CDN、外部字体或其他网络运行时。

## 发布到 GitHub Pages

1. 在 GitHub 新建仓库。
2. 解压 ZIP，把其中的**所有文件和文件夹内容**上传到仓库根目录，确认能直接看到 `index.html`、`game.js`、`styles.css` 和 `.nojekyll`。
3. 提交到 `main` 分支。
4. 打开 **Settings → Pages**，选择 **Deploy from a branch**。
5. 选择 `main` 分支和 `/(root)` 目录并保存。
6. 等待发布完成，使用 GitHub Pages 显示的地址访问。后续推送 `main` 分支会自动更新。

存档保存在当前浏览器的 `localStorage`，清除网站数据会删除进度。
